# Panduan Penggunaan Aplikasi Data Ketidakhadiran

Aplikasi ini digunakan untuk mencatat dan mengelola data ketidakhadiran peserta training di lingkungan PT Indomarco Prismatama.

## Fitur Utama

### 1. Dashboard
- Menampilkan ringkasan data ketidakhadiran secara real-time.
- Memantau tren ketidakhadiran berdasarkan kategori dan cabang.

### 2. Input Data
- Digunakan untuk mencatat ketidakhadiran peserta training utama.
- Wajib mengisi data identitas peserta, jabatan, cabang, jenis training, batch, tanggal, alasan ketidakhadiran, dan mengunggah bukti berita acara (format JPG/PNG).

### 3. Input Data Tambahan
- Digunakan untuk mencatat peserta tambahan yang tidak masuk dalam daftar utama.
- Memiliki fitur unggah foto bukti pendukung.
- Tersedia fasilitas untuk menghapus data secara satuan atau menghapus seluruh data tambahan.

### 4. Riwayat Data Input
- Menampilkan daftar lengkap input data yang telah dilakukan.
- Memungkinkan pencarian dan pemfilteran data.

### 5. Cetak Bukti PDF
- Mencetak laporan bukti ketidakhadiran ke dalam format PDF.
- Mendukung berbagai format cetak (Bukti Foto Horizontal, dll).
- Memungkinkan filter berdasarkan jenis training, bulan, dan tahun.

### 6. Impor/Ekspor Excel/CSV
- Memfasilitasi perpindahan data dengan format Excel atau CSV.

---
*Panduan ini ditujukan untuk internal administrator aplikasi.*
